# **SaveMyItems**
This Mod adds Inventory Backups to your Minecraft Server, bringing better management to the vanilla game especially to restore bugged or lost items


![Preview](https://i.postimg.cc/ZKqh3vvT/invbackup.png)

## Features
* Restore the whole Inventory
* Restore a single Item
* Choose the receiving target
* Audit logs
* Configurable Backup interval (ingame)

## Disclaimer

This mod is a one-person effort. Expect bugs and unexpected behavior!
Bug reports are greatly appreciated here: [Github SaveMyItems Issues](https://github.com/mastercion/minecraft_mod_fabric_sami/issues)
